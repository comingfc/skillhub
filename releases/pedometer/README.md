## 安装说明

这是 **debug 签名** 包，不是应用商店的正式发布包。安装前请在系统设置中允许「未知来源」或「安装未知应用」（不同 Android 版本文案略有差别）。若手机已装过同包名的正式版或其它签名版本，需要先卸载再安装，否则会因签名不一致而失败。

下载后可用下面的命令核对文件：

```bash
sha256sum pedometer-v2.1-debug.apk
```
