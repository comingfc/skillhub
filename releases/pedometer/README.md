## 安装说明

- 本包使用 **debug 签名**，仅供测试安装，不是应用商店正式发布包。
- Android 默认会拦截未知来源的安装。请在系统设置中允许当前浏览器或文件管理器「安装未知应用 / 未知来源」，再打开 APK 完成安装。
- 若手机上已有正式签名的同名应用，需要先卸载后再安装本 debug 包，否则会因签名不一致而失败。
