## 安装说明

- 本包为 **debug 签名**，不是应用商店正式发布包。
- 安装前请在系统设置中允许 **未知来源**（或「安装未知应用」）安装此来源的应用。
- 若手机已装过同包名的正式版或其它签名版本，需先卸载再安装，否则会因签名不一致而失败。
